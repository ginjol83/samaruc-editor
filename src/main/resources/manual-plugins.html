1) Introduccion

SamaruC Editor incluye un sistema de plugins basado en Java ServiceLoader que permite extender la aplicacion sin tocar su codigo fuente. Este documento explica como crear, empaquetar e instalar un plugin.

2) Arquitectura general

La arquitectura se basa en una interfaz comun Plugin. SamaruC descubre e instancia las implementaciones al arrancar y ejecuta su ciclo de vida.

MetodoCuando se llama
onLoad(ctx)Justo despues de cargar el JAR. Guarda el contexto.
onEnable()Cuando la UI esta lista. Agrega menus/componentes.
onDisable()Al desactivar plugin o cerrar app. Limpia recursos.
getName()Devuelve el nombre visible del plugin.

3) Requisitos previos

  • JDK 17 o superior
  • Maven 3.8+ (o Gradle)
  • JAR principal de SamaruC para compilar contra interfaces

Consejo: instala el JAR del host en tu repo local Maven:

mvn install:install-file -Dfile=retro-editor-1.0-SNAPSHOT.jar ^
  -DgroupId=com.retroeditor -DartifactId=retro-editor ^
  -Dversion=1.0-SNAPSHOT -Dpackaging=jar

4) Crear el proyecto Maven del plugin

Estructura minima:

mi-plugin/
  pom.xml
  src/main/java/...
  src/main/resources/META-INF/services/...

pom.xml minimo:

<project ...>
  <modelVersion>4.0.0</modelVersion>
  <groupId>com.miplugin</groupId>
  <artifactId>mi-plugin</artifactId>
  <version>1.0.0</version>
  <packaging>jar</packaging>

  <dependencies>
    <dependency>
      <groupId>com.retroeditor</groupId>
      <artifactId>retro-editor</artifactId>
      <version>1.0-SNAPSHOT</version>
      <scope>provided</scope>
    </dependency>
    <dependency>
      <groupId>org.openjfx</groupId>
      <artifactId>javafx-controls</artifactId>
      <version>17.0.10</version>
      <scope>provided</scope>
    </dependency>
  </dependencies>
</project>

Importante: usa provided para dependencias que ya aporta el host.

5) Implementar la interfaz Plugin

package com.miplugin;

import com.retroeditor.plugin.Plugin;
import com.retroeditor.plugin.PluginContext;
import javafx.application.Platform;
import javafx.scene.control.Menu;
import javafx.scene.control.MenuItem;

public class MiPlugin implements Plugin {
    private PluginContext context;
    private Menu miMenu;

    @Override
    public void onLoad(PluginContext context) {
        this.context = context;
        context.log("MiPlugin cargado correctamente.");
    }

    @Override
    public void onEnable() {
        Platform.runLater(() -> {
            miMenu = new Menu("Mi Plugin");
            MenuItem saludar = new MenuItem("Saludar");
            saludar.setOnAction(e -> context.log("Hola desde MiPlugin!"));
            miMenu.getItems().add(saludar);
            context.registerMenu(miMenu);
        });
    }

    @Override
    public void onDisable() {
        context.log("MiPlugin desactivado.");
    }

    @Override
    public String getName() {
        return "Mi Plugin de Ejemplo";
    }
}

7) Usar PluginContext

MetodoDescripcion
getPrimaryStage()Stage principal para dialogos modales.
getScene()Scene principal del host.
getMenuBar()MenuBar para integraciones.
log(String)Escribe en la pestaña Monitor.
registerMenu(Menu)Registra menu con limpieza automatica.
unregisterMenu(Menu)Elimina menu manualmente.
unregisterAll()Limpia todo lo registrado por el plugin.

Ejemplo: abrir dialogo con Stage del host

@Override
public void onEnable() {
    Platform.runLater(() -> {
        Menu menu = new Menu("Herramientas");
        MenuItem abrirDialogo = new MenuItem("Abrir mi dialogo");
        abrirDialogo.setOnAction(e -> {
            Stage dialogo = new Stage();
            dialogo.initOwner(context.getPrimaryStage());
            dialogo.setTitle("Mi herramienta");
            dialogo.show();
        });
        menu.getItems().add(abrirDialogo);
        context.registerMenu(menu);
    });
}

8) Empaquetar e instalar

Empaquetar:

mvn package

Genera target/mi-plugin-1.0.0.jar.

No uses shade para evitar duplicar clases del host.

Instalacion opcion A (UI de SamaruC)

  1. Abrir SamaruC.
  2. Ir a Archivo / Configuracion.
  3. Pestana Plugins.
  4. Instalar plugin (.jar).
  5. Se copia a carpeta plugins/.
  6. Recargar plugins.

Instalacion opcion B (manual)

Samaruc/
+-- Samaruc.exe
+-- app/
|   +-- samaruc-1.0-SNAPSHOT.jar
+-- plugins/
    +-- mi-plugin-1.0.0.jar

9) Habilitar y deshabilitar plugins

  • Ver lista de JARs en plugins/.
  • Cambiar estado habilitado/deshabilitado.
  • Recargar para aplicar sin reiniciar.

El estado se guarda en ~/.retroeditor.plugins.properties.

11) Buenas practicas y limitaciones

Buenas practicas

  • Usa siempre Platform.runLater() para tocar UI.
  • Limpia recursos en onDisable().
  • Prefiere registerMenu() para limpieza automatica.
  • Declara provided en dependencias del host.
  • Versiona y usa paquetes claros para evitar conflictos.

Limitaciones actuales

  • No hay extension para reemplazar editor o arbol de proyecto.
  • No hay dependencias entre plugins gestionadas por el host.
  • La carga se hace desde plugins/ del directorio de trabajo.
  • No existe aun API completa para contenido del editor abierto.
