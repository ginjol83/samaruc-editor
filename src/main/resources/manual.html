🎯 Introducción

Retro Editor es un entorno de desarrollo integrado (IDE) especializado para programación en lenguaje C, diseñado con una interfaz moderna y funcional basada en JavaFX.

Características principales:

  • ✅ Editor de código con resaltado de sintaxis para C/C++
  • ✅ Gestión de proyectos con explorador de archivos integrado
  • ✅ Compilación y ejecución directa desde el IDE
  • ✅ Terminal integrada con consola de salida y depuración
  • ✅ Búsqueda avanzada en archivos y proyectos completos
  • ✅ Pestañas múltiples para trabajar con varios archivos simultáneamente
  • ✅ Interfaz personalizable con temas claro y oscuro
  • ✅ Soporte multiidioma (Español/Inglés)
  • ✅ Deshacer/Rehacer con historial ilimitado
  • ✅ Iconos FontAwesome 5 para una interfaz moderna
📌 Nota: Este editor está optimizado para desarrollo de aplicaciones C, especialmente orientado a proyectos retro y desarrollo para Game Boy usando GBDK.

⚙️ Instalación y Requisitos

Requisitos del Sistema

  • Java: JDK 17 o superior
  • Maven: 3.6 o superior (para compilar desde código fuente)
  • Compilador C: GCC, MinGW o GBDK (según tu proyecto)
  • Sistema Operativo: Windows, Linux o macOS

Instalación desde Código Fuente

Para compilar y ejecutar el editor desde el código fuente:

  1. Clona o descarga el repositorio del proyecto
  2. Abre una terminal en el directorio del proyecto
  3. Ejecuta los siguientes comandos: 
    mvn clean compile
mvn install
mvn javafx:run

Instalación desde Ejecutable

Si tienes el paquete ejecutable (.exe en Windows):

  • Extrae el archivo RetroEditor-win.zip
  • Ejecuta RetroEditor.exe
  • No requiere instalación de Java (incluye runtime embebido)

📂 Gestión de Proyectos

Crear un Nuevo Proyecto

  1. Haz clic en el botón Nuevo Proyecto 📁 o usa el menú Archivo → Nuevo Proyecto
  2. Selecciona o crea una carpeta para el proyecto
  3. El explorador mostrará la estructura del directorio
  4. Comienza a crear archivos .c y .h

Abrir un Proyecto Existente

  1. Haz clic en Abrir Proyecto 📂 o usa el menú Archivo → Abrir Proyecto
  2. Navega hasta la carpeta del proyecto
  3. Selecciona el directorio raíz del proyecto
  4. Todos los archivos del proyecto aparecerán en el explorador
💡 Consejo: Organiza tus proyectos con subdirectorios (src/, include/, build/) para mejor estructura y mantenimiento.

Trabajar con Archivos

  • Crear archivo nuevo: Botón "Nuevo" o Ctrl+N
  • Abrir archivo: Doble clic en el explorador o botón "Abrir"
  • Guardar archivo: Ctrl+S o botón "Guardar"
  • Guardar como: Menú Archivo → Guardar Como
  • Cerrar archivo: Botón "Cerrar" o click en X de la pestaña

✏️ Edición de Código

Resaltado de Sintaxis

El editor proporciona resaltado automático para:

  • Palabras clave: if, else, for, while, return, struct, etc.
  • Comentarios: // comentarios de línea y /* bloques */
  • Cadenas: "texto entre comillas"
  • Números: 123, 0xFF, 3.14
  • Funciones: printf, scanf, main
  • Directivas: #include, #define, #ifdef

Operaciones de Edición

Operación Atajo Descripción
Deshacer Ctrl+Z Revierte la última acción
Rehacer Ctrl+Y Restaura la acción deshecha
Cortar Ctrl+X Corta el texto seleccionado
Copiar Ctrl+C Copia el texto seleccionado
Pegar Ctrl+V Pega desde el portapapeles
Seleccionar todo Ctrl+A Selecciona todo el texto

Características Avanzadas

  • Numeración de líneas: Siempre visible para referencia
  • Múltiples pestañas: Trabaja con varios archivos simultáneamente
  • Detección de cambios: Asterisco (*) indica archivos modificados no guardados
  • Historial ilimitado: Deshacer/Rehacer sin límites

🔍 Búsqueda de Texto

Buscar en Archivo Actual

  • Presiona Ctrl+F o haz clic en el botón de búsqueda 🔍
  • Se abre un panel de búsqueda en la parte superior del editor
  • Escribe el término a buscar
  • Navega entre resultados con los botones Anterior/Siguiente
  • Opción de reemplazo de texto disponible

Buscar en Todo el Proyecto

  • Presiona Ctrl+H o usa el botón 🔍+ en la barra de herramientas
  • Busca en todos los archivos del proyecto
  • Los resultados muestran archivo, línea y contexto
  • Haz doble clic en un resultado para abrir el archivo en esa ubicación
💡 Consejo: Usa la búsqueda en proyecto para encontrar definiciones de funciones, referencias a variables o identificar dónde se usa una función específica.

🔨 Compilación y Ejecución

Compilar el Proyecto

  1. Asegúrate de tener un proyecto abierto con archivos .c
  2. Haz clic en el botón Compilar 🔨 o usa el menú Compilación → Compilar
  3. La salida de compilación aparece en la consola inferior
  4. Los errores y warnings se muestran con detalles de línea y archivo

Ejecutar el Programa

  1. Después de compilar exitosamente, haz clic en Ejecutar ▶️
  2. El programa se ejecuta y la salida aparece en la consola
  3. La entrada interactiva también está disponible en la consola

Configurar el Compilador

El editor soporta diferentes compiladores C:

  • GCC: Compilador GNU para C/C++
  • MinGW: GCC para Windows
  • GBDK: Game Boy Development Kit

Configura la ruta del compilador en Configuración → Compilador

📌 Nota: Asegúrate de que el compilador esté en el PATH del sistema o configura la ruta completa en las preferencias.

Consola de Depuración

⚙️ Configuración y Personalización

Configuración de Idioma

  1. Abre Configuración → Preferencias o haz clic en el botón ⚙️
  2. Ve a la pestaña Idioma
  3. Selecciona entre Español o Inglés
  4. Haz clic en Guardar
  5. La interfaz se actualiza automáticamente

Configuración del Compilador

  1. Abre las preferencias (⚙️)
  2. Ve a la pestaña Compilador
  3. Especifica la ruta completa al ejecutable del compilador
  4. Ejemplo: C:\MinGW\bin\gcc.exe o /usr/bin/gcc
  5. Guarda los cambios

Temas Visuales

El editor incluye dos temas:

  • Tema Claro: Fondo blanco, ideal para ambientes iluminados
  • Tema Oscuro: Fondo oscuro, reduce fatiga visual en ambientes con poca luz

Alterna entre temas usando el botón 🌓 en la barra de herramientas.

Archivo de Configuración

Las preferencias se guardan en: ~/.retroeditor.properties

Puedes editar manualmente este archivo si es necesario.

❓ Preguntas Frecuentes (FAQ)

¿Cómo cambio el compilador que usa el editor?

Ve a Configuración → Preferencias → Compilador e introduce la ruta completa al ejecutable de tu compilador preferido.

¿Puedo usar el editor para C++ además de C?

Sí, el resaltado de sintaxis soporta tanto C como C++. Asegúrate de configurar el compilador apropiado (g++ para C++).

¿Dónde se guardan mis configuraciones?

En el archivo .retroeditor.properties en tu directorio home (~/ en Linux/Mac, %USERPROFILE% en Windows).

No veo la salida de mi programa en la consola

Asegúrate de que el programa se ha compilado sin errores. Verifica también que estés mirando la pestaña correcta (Consola vs Depurador).

¿Cómo puedo depurar mi código?

Actualmente el editor muestra la salida de compilación. Para depuración interactiva, puedes usar printf() en tu código o usar herramientas externas como gdb.

¿El editor soporta plugins?

El editor tiene una arquitectura de plugins. Puedes colocar archivos JAR de plugins en la carpeta plugins/ junto al ejecutable.

¿Cómo contribuyo al proyecto?

Este es un proyecto de código abierto. Puedes revisar el código fuente, reportar bugs o contribuir con mejoras a través del repositorio del proyecto.

¿Qué versión de Java necesito?

Java 17 o superior es necesario para ejecutar el editor desde código fuente. La versión empaquetada incluye su propio runtime.
