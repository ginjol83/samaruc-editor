Manual de Samaru C Retro Editor

Introducción Proyectos Edición Compilación/Ejecución Configuración

Introducción

Retro Editor es un editor modular para C con explorador de archivos, consola y soporte para proyectos.

Proyectos

Desde el menú o la barra de herramientas puedes crear o abrir proyectos existentes.

Edición

Abre, edita y guarda archivos fuente C. Usa las pestañas para trabajar con varios archivos a la vez.

Compilación/Ejecución

Compila y ejecuta tus programas desde el menú o la barra de herramientas. La salida aparece en la consola inferior.

Configuración

Personaliza el idioma y otras opciones desde el menú de configuración.
